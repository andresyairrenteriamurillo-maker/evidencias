# Mis Evidencias Docentes

Página para registrar durante el año las evidencias de la Evaluación Anual de Desempeño Docente (Decreto 1278).
Tomas la foto, escribes lo que hiciste y eliges la competencia y el seguimiento (S1, S2 o S3).
Al final generas un .zip con una carpeta por competencia y un Word por evidencia, con fotos, portada, carta de entrega y Anexo 2.

## Cómo publicarla en GitHub (una sola vez)

1. Crea una cuenta en https://github.com (si no tienes).
2. Arriba a la derecha toca **+** → **New repository**.
   - Repository name: `evidencias`
   - Marca **Public**
   - Toca **Create repository**.
3. En la página del repositorio toca **uploading an existing file**.
4. Arrastra **todo el contenido de esta carpeta** (el archivo `index.html`, el `README.md` y la carpeta `lib`) y toca **Commit changes**.
   - Importante: la carpeta `lib` debe quedar subida con sus dos archivos (`docx.js` y `jszip.min.js`).
5. Ve a **Settings** → **Pages** (menú de la izquierda).
   - En *Branch* elige **main** y carpeta **/ (root)** → **Save**.
6. Espera 1 o 2 minutos y recarga. Arriba aparecerá tu enlace, algo como:
   `https://TU-USUARIO.github.io/evidencias/`
7. Abre ese enlace en el celular y, en el menú de Chrome, elige **Agregar a la pantalla principal**. Queda como una app.

## Cómo se usa

- **Configuración**: al iniciar el año, revisa tus datos, el año, las fechas de los seguimientos y copia las competencias del Anexo 5 concertado. Toca **Guardar configuración**.
- **Registrar**: elige la competencia y el seguimiento, escribe qué se hizo, agrega fotos con su descripción y guarda. Puedes hacer varios registros para el mismo seguimiento.
- **Mis evidencias**: muestra el avance del año. En rojo están los seguimientos que aún no tienen nada.
- **Generar Word**: descarga el .zip con todas las carpetas listas para entregar.

## ✨ Redactar con IA

La página puede escribir el texto de cada evidencia a partir de las fotos y de unas notas cortas.

1. Consigue una clave gratis de Google Gemini en https://aistudio.google.com/apikey (con tu cuenta de Google, botón **Create API key**).
2. En la página ve a **⚙️ Configuración → Inteligencia artificial**, pega la clave, toca **Guardar clave** y luego **Probar**.
3. Al registrar: agrega las fotos, escribe unas notas cortas en "¿Qué se hizo?" y toca **✨ Redactar con IA**.
4. Revisa el texto, completa lo que quede entre [corchetes] y guarda.

La clave se guarda solo en tu dispositivo. La IA no inventa cifras: lo que no sepa lo deja entre corchetes para que lo completes.

## Si no se descarga el Word

Algunos navegadores (por ejemplo Brave) bloquean la descarga automática. Después de generar aparece el botón **⬇️ Si no se descargó solo, toca aquí**. Si sale un mensaje rojo de error, toma una captura.

## Importante: dónde quedan guardados los datos

Las evidencias se guardan **dentro del navegador del dispositivo** donde las registras (no se suben a GitHub ni a internet).

- Si borras los datos del navegador o cambias de celular, se pierden.
- Usa **Generar Word → Descargar copia** con frecuencia (por ejemplo, cada mes) y guarda ese archivo en Google Drive o en el computador.
- Para pasar las evidencias del celular al computador: descarga la copia en el celular y, en el computador, usa **Cargar copia**.
